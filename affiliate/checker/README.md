# 表記チェック（M2）v0

ルール辞書（`rules.json`）で、提携メディアの記事から確認すべき表現の候補を拾い、レポート（Markdown）と一覧（CSV）を出す。**法的な判断はしない一次チェック。** v1 で Claude による文脈の判定と修正依頼文の作成を足す（API キーが必要）。

## 使い方
```
python3 check.py --urls-file urls.txt --brand 商品名 --out report.md --csv findings.csv
```
- Python 3.9 以上、標準ライブラリだけで動く
- 公開ページだけを取得し、robots.txt に従い、同じサイトへは3秒以上空ける
- サンプル: `sample-report.md`（架空の記事3本で作成）
- テスト: `python3 tests/test_check.py`

## どこで動かすか（オーナーが選ぶ）
| 場所 | 長所 | 短所 |
|---|---|---|
| **コワーク（オーナーのPC）** | 指示文を貼るだけ。顧客名がネットに出ない | PC が起きている必要がある |
| オーナーのPCで直接実行 | 速い | コマンドを打つ必要がある |
| クラウド（Google Cloud Run など） | 定期実行できる | 設定と費用（小さい）が要る。M1 と一緒に作るのがよい |
| GitHub Actions | 無料 | **このリポジトリは公開なので、実行ログに顧客名・URL が出てしまう。使わない** |

推奨: リリース時はコワーク、顧客が増えたらクラウド。

## ルール辞書の育て方
- 誤検知（問題ないのに拾った）と見落とし（拾えなかった）を下の記録に足し、`rules.json` を直す
- 直したら `tests/` に例を足してテストを通す
- 根拠の条文・ガイドラインは、公的な一次情報で確認して書く（`ad-compliance-checker` 担当）
