# 目的
サービスLP「アフィまかせ」用に Google アナリティクス 4 のプロパティを作り、計測に必要な設定を済ませ、測定IDとプロパティIDを PM に渡す。

# 前提
- 公開URLは、次のドキュメントの「01」の結果にある: https://docs.google.com/document/d/1h3CYlzcAakR8DB2nmBx2qvGakh9Z7z5Zahi3_SNWSzM/edit
- 計測コードはサイト側に入っているので、タグの設置作業は不要。

# 守ること
- 指示にない設定・削除はしない。既存のプロパティやアカウントは変更しない。迷ったら止まって確認する。
- Google 広告・BigQuery などとのリンク、有料版への申込はしない。
- 利用規約への同意画面が出たら、オーナーに同意を頼む。

# 手順
1. 上のドキュメントを開き、「01」の公開URLを控える。まだ記載がなければ止まってオーナーに伝える。
2. https://analytics.google.com/ を開き、管理（歯車）→「作成」→「アカウント」で新しいアカウントを作る:
   - アカウント名: アフィまかせ
   - データ共有の設定: 初期値のまま
3. プロパティを作る:
   - プロパティ名: アフィまかせ サービスサイト
   - タイムゾーン: 日本 ／ 通貨: 日本円
   - ビジネスの説明: 業種「ビジネス・産業」（なければ近いもの）、規模「小規模」、目的「見込み顧客の獲得」
4. データストリーム「ウェブ」を作る:
   - URL: 手順1の公開URL（https:// を除いた部分）
   - ストリーム名: サービスLP
   - 拡張計測機能: オンのまま。ただし歯車から「フォームの操作」だけオフにして保存
5. 管理 →「データの収集と修正」→「データ保持」で、イベントデータの保持期間を「14か月」にして保存。
6. 管理 →「カスタム定義」→「カスタムディメンションを作成」で、次の5つを作る（範囲はすべて「イベント」、ディメンション名とイベントパラメータは同じ文字列）:
   page_id / form_id / step / step_name / traffic_type
7. 管理 →「イベント」→「キーイベント」（または「主要イベント」）→「新しいキーイベント」で、次の2つを登録する:
   generate_lead / diagnosis_complete
8. 管理 →「データストリーム」→ 作ったストリームを開き、「測定ID」（G- で始まる）を控える。
9. 管理 →「プロパティの詳細」を開き、「プロパティID」（数字）を控える。
