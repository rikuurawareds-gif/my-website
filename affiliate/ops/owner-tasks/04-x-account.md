# 目的
サービス「アフィまかせ」の X アカウントを作り、プロフィールを整える。投稿はしない（投稿は 07 で設定する自動投稿の仕組みが行う）。

# 前提
- 公開URLは、次のドキュメントの「01」の結果にある: https://docs.google.com/document/d/1h3CYlzcAakR8DB2nmBx2qvGakh9Z7z5Zahi3_SNWSzM/edit
- アイコン画像: https://drive.google.com/file/d/1Wf6cGcDeTQsuC6UaO4RpuMrw_YB8KB21/view
- ヘッダー画像: https://drive.google.com/file/d/1mBhQwLO5VIVb3Ki64W3d0vLBrtnW3t94/view

# 守ること
- 投稿・フォロー・いいね・DM・有料プラン（Premium等）の申込はしない。
- オーナーの個人アカウントにログインしている場合は、それを変更しない。一度ログアウトしてよいかオーナーに確認してから新規作成に進む。
- メールアドレスはオーナーに聞く。パスワード、SMS・メールの認証コード、CAPTCHA、画像のファイル選択は、止まってオーナーに頼む。
- 生年月日など本人の情報が必要な項目は、オーナーに聞いて入力する。架空の情報は入れない。

# 手順
1. 上のドキュメントを開き、「01」の公開URLを控える。
2. 2つの画像を開き、それぞれダウンロードしておく。
3. https://x.com/i/flow/signup でアカウント作成を始める。名前は「アフィまかせ」。メールアドレスはオーナーに聞く。電話番号はオーナーの既存の番号を使ってよい（入力と SMS 認証はオーナーに頼む）。パスワードもオーナーに頼む。
4. ユーザー名を次の順に試し、空いている最初のものにする: afimakase → afi_makase → afimakase_jp → afimakase_official
5. プロフィールを編集する:
   - 名前: アフィまかせ｜アフィリエイト運用の手離れ
   - 自己紹介: 広告主のアフィリエイト運用を、まるごと手離れ。ASP・メディア対応、成果承認、記事の表記チェック、レポートまでAIと担当者で引き受けます。運用のコツとステマ規制の注意点を発信中。1分の無料工数診断はこちら↓
   - ウェブサイト: 手順1の公開URL の末尾に ?utm_source=x&utm_medium=social&utm_campaign=profile を付けたもの
   - 場所: 空欄
   - アイコンとヘッダー: 手順2の画像。ファイル選択はオーナーに頼む
6. 保存後、プロフィール画面を開き、名前・自己紹介・リンク・画像が反映されていることを確認する。
