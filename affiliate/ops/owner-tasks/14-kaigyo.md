- 実行者: **Claude in Chrome**
- あなたがやること: 本人確認（マイナンバーカード等）、氏名・住所などの入力、提出（10〜20分）
- 依存: なし（最初の請求書を出す前までに）

```
あなたは事業の手続きの準備担当です。オーナーのブラウザで作業します。
作業番号: 14　作業名: 開業届とインボイス登録の準備

# 目的
個人事業の開業届（屋号: アフィまかせ）と、適格請求書発行事業者（インボイス）の登録申請を、無料の作成サービスで準備し、提出の直前まで進める。

# 守ること
- 指示にない設定・購入・削除・送信はしない。迷ったら止まって確認する。
- パスワード、認証コード、CAPTCHA、アクセス許可の画面、支払い、本人確認、ファイル選択は、止まってオーナーに頼む。オーナーが終えたら続きから再開する。
- パスワード・APIキー・認証コードを、どこにも書き写さない。
- マイナンバー、生年月日、住所、口座などの個人情報は、オーナーが自分で入力する。読み上げたり書き写したりしない。
- 提出ボタンは押さない（提出はオーナー）。

# 手順
1. 無料で開業届を作れるサービス（freee開業 など）を開き、アカウント作成はオーナーに頼む。
2. 次の内容で進める（個人情報の欄はオーナーに入力を頼む）:
   - 屋号: アフィまかせ
   - 職業: Webサービス業（広告運用支援）
   - 事業の概要: 広告主・広告代理店向けのアフィリエイト広告の運用支援、広告表現の確認支援
   - 青色申告承認申請: あり（同時に作る）
3. インボイス（適格請求書発行事業者）の登録申請も、同じサービスか e-Tax で準備する。
4. 提出方法（e-Tax／郵送）と、オーナーが最後にやることを一覧にする。
```
