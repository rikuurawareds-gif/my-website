# オーナーの作業（貼るだけ）

オーナーにしかできない作業を、Claude in Chrome かコワークに貼るだけにした指示文の一覧。作り方は `/sagyo-bunsyo`（`.claude/skills/sagyo-bunsyo/SKILL.md`）。

**使い方**: 指示文を貼る → 頼まれたときだけ数秒の操作をする → 終わったら PM に「終わった」とだけ伝える。結果は各エージェントが Drive の [作業結果の受け渡し](https://docs.google.com/document/d/1h3CYlzcAakR8DB2nmBx2qvGakh9Z7z5Zahi3_SNWSzM/edit) に書き、PM がそこから読んで次に進む。

| # | 作業 | 貼る場所 | あなたの操作 | 依存 | 状態 |
|---|---|---|---|---|---|
| 01 | サイトの公開（Cloudflare Pages） | Chrome | メール認証、GitHub連携の許可（約1分） | なし | **完了**（2026-11-26） |
| 02 | アクセス解析の設定（GA4） | Chrome | ほぼなし | 01 | 未着手 |
| 03 | 相談フォームの送信先（Apps Script） | Chrome | 権限の許可（約30秒） | なし | 未着手 |
| 04 | X のサービスアカウント開設 | Chrome | メールアドレスを伝える、SMS認証・パスワード・画像選択（約3分） | 01 | 未着手 |
| 05 | ASP（広告主側）のCSV形式の収集 | Chrome | 各ASPへのログイン | なし | 未着手 |
| 06 | 営業先リストの作成（30社） | コワーク | なし | なし | 未着手 |
| 07 | X の自動投稿の設定（X API＋Apps Script） | Chrome | 規約への同意、APIのチャージ（カード）、権限の許可（約2分） | 01・04 | 未着手 |

**おすすめの順番**: 01・03・05・06 を並行で → 01 が終わったら 02・04 → 04 が終わったら 07。

PM が受け渡しを読んだ後にやること:
- 01 → `docs/hosting.md` に公開URLを記録
- 02・03 → `site/assets/config.js` に測定IDと送信先URLを入れて公開
- 04 → `marketing/x-account.md` にユーザー名を記録
- 07 → 12/1 の最初の投稿の後、固定ポストにする作業を指示文にする。以後の投稿文は PM が `X投稿キュー.csv` に追加する
- 05 → `automation/asp-formats/<ASP名>.md` と変換処理を作る
- 06 → 優先度Aの会社のサンプル表記チェックと連絡文の下書きを作る（送る前にオーナーが承認）
