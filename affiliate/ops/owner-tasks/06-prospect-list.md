```
あなたは営業リストの調査担当です。
作業番号: 06　作業名: 営業先リストの作成（30社）

# 目的
アフィリエイト広告をすでに使っていて、運用の手間が大きそうな広告主を30社見つけ、スプレッドシート「営業先リスト」に記録する。

# 前提
- 記録先: https://docs.google.com/spreadsheets/d/17w_vuocYF0R_rW-VN4n--5sRIjE2NVb1ZhlEKSpbtok/edit （1行目が見出し。その下に追記）
- 狙う業種: 転職・人材紹介、美容・健康（サプリ、脱毛、スキンケア）、金融（カードローン、証券、保険）、通信（光回線、格安SIM）、サブスク
- 業種ごとに6社前後。

# 守ること
- 公開されている情報だけを使う。ログインが必要なページや有料データは使わない。
- 連絡はしない（問い合わせフォームへの送信、メール送信は禁止）。
- 個人名・個人のメールアドレス・電話番号は記録しない。会社名と、公式の問い合わせフォームのURLまで。
- 検索結果は普通に検索して見る。大量の自動取得はしない。

# 手順
1. 業種ごとに「〇〇 おすすめ」「〇〇 比較」「〇〇 ランキング」で検索し、上位の比較・ランキング記事を3〜5本開く。
2. 記事に載っている商品・サービスと運営会社を書き出す。複数の記事に載っている会社ほど優先度を上げる。
3. 記事の広告リンクや「PR」表記から、アフィリエイトを使っている根拠となる記事のURLを1つ控える。
4. 各社について、記事の中に次の点がないかを1本だけ確認し、あれば「表記リスクの有無」に短く書く（法的な判断はしない。「確認が必要そう」という書き方にする）:
   - 広告であることの表記（PR・広告）が見当たらない、または末尾にしかない
   - 「No.1」「最安」など、根拠の書かれていない最上級の表現
5. 会社の公式サイトで、問い合わせフォームのURLを探す。
6. スプレッドシートに1社1行で記録する:
   ID（S001から連番）／会社名／商品・サービス／業種／見つけた経路（比較記事）／アフィリエイト利用の根拠（記事URL）／推定の掲載メディア数（見つけた記事の数）／推定の利用ASP（リンクから分かれば）／表記リスクの有無／問い合わせ窓口（URL）／優先度（A: 3本以上の記事に載り表記リスクあり、B: どちらか、C: それ以外）
   アプローチ日・反応・メモは空欄。

# 終わったら
1. 次の Google ドキュメントの一番下に追記する: https://docs.google.com/document/d/1h3CYlzcAakR8DB2nmBx2qvGakh9Z7z5Zahi3_SNWSzM/edit
   ## 06 営業先リストの作成（YYYY-MM-DD HH:MM）

   - 結果: 記録した社数=、うち優先度A=
   - オーナーの対応が必要なこと: （なければ「なし」）
2. オーナーに、終わったことを短く伝える。
```
