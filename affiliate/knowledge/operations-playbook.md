# アフィリエイト運用の考え方

出典の事例番号を `［事例001］` のように付ける。1事例だけの学びは「仮説」扱い。複数事例で確かめたら「定石」に格上げする。

## 1. 何を最大化するか

- 広告主の目標は **件数** と **質（収益性）** の2つで、たいてい両立しない。伸ばすほどROASは下がる。［事例001］
- 質の指標は成果地点の先で見る。人材なら登録 → 面談 → 成約、ECなら購入 → 継続。**ROAS = 成果の先の売上 ÷ 費用（代理店手数料込み）** で見るのが基本。［事例001］
- 広告主は件数以外に「守る条件」を持っている（例: 雇用形態の比率、転職時期）。これは承認基準と媒体の評価軸になる。最初のヒアリングで必ず聞く。［事例001］
- 提案は「件数とROASの関係」を数本のプランで見せ、広告主に選んでもらう。ROASの下限を決めてもらうと話が進む。［事例001］

## 2. チャネル（メディアの種類）と役割

| チャネル | 特徴（傾向） | 役割 |
|---|---|---|
| SNS・広告系（メディアが広告を出して送客する型） | 成約率は低め、登録単価も低い。件数の伸びしろが大きい。大手が手薄なことがある | **件数を大きく取る** |
| リスティング・SEO（比較・ランキング） | 成約率が高め。上位面は大手の取り合いで単価が高騰しやすい | **質の高い件数を積む**。効率の合う範囲で |
| 求人サイト・送客型 | 成約率が低めになりやすい | **効率を守る**。悪い面を外す |
| アグリゲーション・専門メディア（固定費＋超過の契約もある） | 成約率・ROASが高いが伸びしろは小さい | **大きく触らない** |

- すべてのチャネルで同じROASを狙わない。役割を分け、全体で釣り合いを取る。［事例001］
- 競合の取り合いの面（例: 比較サイト上位を大手が独占）で同じ土俵に乗ると、ROASが割れる。チャネルごとに戦い方を変える。［事例001］

## 3. 打ち手は3種類

1. **質の低い層を減らす**: 掲載面・フォーム・配信設定で外す（効果が大きい）、訴求を変えて寄せる（効果は中程度）。［事例001］
2. **単価を見直す**: 上位の掲載面や配信量を取りにいく。ただし「単価を2倍にしても件数が倍になる例は少ない」。［事例001］
3. **訴求・クリエイティブを変える**: 訴求を緩めると対象が広がり件数が伸びる。その分、成約率が下がる。SNS系では件数2〜3倍・成約率4割減程度という媒体側の感覚値がある（仮説）。［事例001］

順番は「悪い面を外す → 条件（単価）を見直す → 配信・掲載を広げる」。新規は「媒体調査 → 条件交渉 → 掲載」。［事例001］

## 4. 媒体の4分類（ポートフォリオ管理）

件数（伸びしろ）と質（ROAS）の2軸で全媒体を分ける。［事例001］

| 分類 | 状態 | 打ち手 |
|---|---|---|
| 強化 | 質が良く、伸びしろがある | 単価・訴求を見直して件数を伸ばす |
| 育成 | 伸びしろはあるが、悪い面が混ざる | 悪い面を外してから伸ばす |
| 改善 | 件数はあるが質が悪い | 悪い面を外してROASを上げる |
| 停止・縮小 | 質も伸びしろも見込めない | 予算をほかへ移す |

「悪い面を外して浮いた予算を、伸ばせる媒体に回す」が基本の動き。

## 5. 改善の判定ルール

- 施策 → 一定件数を貯める → 判定 → 数か月後にROASを確認。1サイクルは4か月程度（小さい媒体は6か月程度）。［事例001］
- **判定件数は精度と速さの釣り合いで決める**。例: 成果の先の率（面談率など）が50%前後のとき、10件では誤差±30%程度で見誤りやすく、30件で±18%程度、60件で±13%程度だが倍の時間と失敗コストがかかる → 30件前後を採用。媒体の規模に合わせて開始前に決める。［事例001］
- 3回に1回はやり直す前提で計画する。訴求・単価は一度に大きく変えず段階的に。悪ければ判定件数の時点で戻す。［事例001］
- 計画は約束しない。半年ごとに実績で引き直す。［事例001］

この判定は `analyst` / `report-builder` が自動で出せるようにする（誤差は二項分布の95%信頼区間で計算）。

## 6. 新規メディアの開拓

**SNS広告系** の探し方（確度の高い順）［事例001］
1. つながりのあるメディアに、別の職種・領域での横展開を頼む
2. 広告ライブラリ（SNSの広告公開ツール）から、同領域で広告を出しているメディアを逆引き
3. 既存メディア・ASPに、同じ領域で取れているメディアを聞く
4. 求職者・購入者としてSNSを見て、配信されている広告から出稿メディアを洗い出す
5. 他領域で実績のある運用者に、新規の立ち上げを打診（時間がかかる）

候補は10媒体程度の規模で持ち、条件（単価の上限、レギュレーション）を先に決めて小さく始め、判定件数で止めるか決める。

**SEO・リスティング系**［事例001］
- 月1回、主要キーワード30〜50個で検索1ページ目の比較媒体を調べる（広告枠と自然検索の両方）
- 分類: **未掲載**（新規掲載を交渉）／**掲載はあるが成果対象外**（公式への直リンク、リンクなし → 成果対象にする交渉）
- 交渉は、その媒体とつながりのあるASPを通す

→ これは M5（メディア開拓）でほぼ自動化できる。

## 7. 季節性

業種ごとに月別の獲得指数（基準月=1.00）を持ち、計画は季節の波を除いた数で比べる。季節要因の減少を「計画からの外れ」と誤解させない。［事例001: 転職は年度替わり前が山、年末と夏が谷］

## 8. リスクの見せ方

- 「確かめられていないこと → 起きた場合 → 備え」の表で示す。［事例001］
- よくあるリスク: 訴求を変えても件数が伸びない／成約率が想定以上に下がる／新規媒体が見つからない／配信面のアルゴリズムや審査の変更／少数媒体への依存（上位2媒体で4割など）／競合の単価引き上げ。
- 「うまくいかない場合も件数とROASのどちらかは守れる」形に計画を組む（伸びなければ訴求を戻す）。［事例001］

## 9. KPIの組み方
- **最重要KPIは遅れて分かる**（例: 成約CPAは半年後にしか確定しない）。そこで、成果の発生時点で分かる **サブKPI（質の比率、そのCPA）を短期の判断に使い、最重要KPIは長期で確認する**。［事例003］
- **損益分岐は層ごとに出す**（例: 正社員・パート・派遣で1件あたりの粗利が違う）。「質の比率が○%まで上がれば、一律単価○円まで払える」という形で、単価の上限を質と結びつけて決める。［事例003］
- 媒体ごとの質の目標は一律にしない。**媒体のポテンシャル（領域のシェア × 掲載順位）でスコア化**して、現実的かつ挑戦的な目標を媒体ごとに置く。［事例011］
- 判断の時点をそろえる（例: 面接から決定までの平均日数を見て、「50営業日経過時点の面接CPA」で判断する）。［事例011］

## 10. 比較メディア（PPC）の単価と順位
- 比較・ランキング面の順位は **実質的に単価の入札**。上位が防衛単価を出すといたちごっこになるので、顧客に **許容できる最大単価** を先に出してもらい、それで交渉する。［事例002・診断資料］
- 1位はメディアのグループ会社の枠で、単価に関係なく取れないことがある。［診断資料］
- **新しい面はいきなり上位を取らない**。3位前後で実際のCVRを見て、EPCが3〜5位でほぼ同じなら無理に上を取らない。［事例002］
- 新しい面の件数は、**1位の実績から逆算** する（1位の件数 ÷ CVR → クリック母数 → 順位によるクリックシェア補正 → 自社のCVR補正）。保守・標準・上限の3段で見せる。［事例002］
- 単価を下げるときは「強化前の単価に戻す」形で段階的に。効率が合わない媒体は「単価ダウンを打診 → 不可なら停止」。［事例002・011］
- 媒体調査では「6位以下の媒体の順位は無理に上げない」「未掲載のうち **競合が載っている媒体** を優先してリクルーティング」。［事例006］
- 件数が上振れしすぎた施策は、一時停止 → 順位調整で再開。［診断資料］

## 11. 質の管理（件数を守りながら質を上げる）
- **質の悪い層を属性の組み合わせで特定し、その配信セグメントを止める**（例: 職種×年収×年齢）。止めると件数も減るので、件数とのトレードオフを毎月書く。［事例010］
- 後工程の率（配布率など）が落ちたら、**未達の内訳を層ごとに数える**（例: 非常勤、60歳以上、対象エリア外）。上位の層から順にメディアへ流入抑制を依頼する。［事例004］
- **掲載面を週次でクローリングする**。メディアは無断で掲載面や訴求を変えることがある。チェック項目の例: ［事例011］
  1. 対象外の層（非常勤・パート・派遣など）向けのランキングに載っていないか
  2. 対象外の層を呼び込む訴求になっていないか
  3. 一度入れてもらった訴求文言が消えていないか
  4. LP や記載されている数字（求人数など）に問題がないか
  5. 顧客が禁止した訴求（例: 根拠のない「上場企業」）を使っていないか
- 比較メディアの中には、主要なキーワードで勝てなくなると、質の低いキーワード（パート・派遣系など）に出稿を寄せるところがある。ASP経由でキーワードの傾向を確認する。［事例011］
- 年代で傾向が逆になることがある（若い層は常勤率が高く短期率が低い、高い年齢層はその逆）。**年代別に訴求（CR）を分けて配信** し、片方ずつ検証する。［事例011］
- 地域で成約率が大きく違う場合は、地域別に配信を寄せる。［事例011］

## 12. SNS広告系メディアの運用
- クリエイティブ（CR）を **フォーマット／カラー／訴求／視認性** の観点で分析し、良い・悪いを理由つきで蓄積する。SNSの投稿のスクリーンショット風の CR は質が悪い傾向があった。［事例011］
- CR単位で質を判断するには、1指標あたり **50〜60件** 程度の成果が必要（それ未満は傾向が読めない）。［事例011］
- **過去のCRと成果の紐づけ** ができないメディアがある。開始前に「CR別・コード別の成果を出せるか」を確認する。［事例011］
- 成果の媒体別内訳が見えないネットワーク型の配信は、何が効いたか分からず横展開できない。開始前に確認する。［事例005］

## 13. 計測とデータ
- **Cookie の有効期間** は ASP ごとに交渉できる。そろえておくと比較がしやすい。掲載停止後も有効期間内は成果が出る（残クッキー）ので、停止時に見込み件数を出しておく。［事例011］
- 一部のコードだけCVRが極端に高い（例: 50%超）ときは、成果より先に **計測と導線の故障** を疑う。［事例004］
- データは「ASPの成果」「顧客の SFA/CRM」「顧客の属性データ（Raw）」の3つを突き合わせる。反映のタイミングが違うので、直近分は「未反映」と注記する。［事例004・011］
- 停止した媒体を再開するには、媒体への再打診と計測テストで2週間程度かかる。［事例005］
- 予算を縮小するときは、費用が発生していない（成果が出ていない）媒体は掲載を続けてよい。［事例005］
- ASP を移すときは、マージン調整・システム接続・規約同意・リンク設定とテストの順で進める。［事例010］

## 14. 異常の早期発見
毎日数字を読み込み、平均や目標から大きく外れた値を検知したら、**異常 → 根本の要因 → 打ち手** の順に分解する（例: 質の悪化 → 短期率の悪化 → 未定率の増加 → 特定メディアで若年層の流入が増えた → 若年層向けのキーワードに寄っていないか確認）。件数が少ない日のブレは「日ブレの可能性」として扱う。［事例011］ → M10 で自動化する。

## 15. 新しいチャネル
- 生成AIの回答画面の広告枠など新しい配信面は、**代理店側が媒体費（クリック課金）を負担し、広告主には成果報酬で請求する** 形にすると、広告主はリスクなしで試せる。［事例002］
- ポイ活系メディア（LINEでヒアリング → オペレーターが案件を案内）など、比較サイト以外の面もある。［事例007］
