# 広告主への提案の型

## 1. 資料の構成（実際に使われた流れ）［事例001］
1. 表紙: 何の提案か ＋ 1行の副題（例: 見通し・体制・費用・段取り）
2. サマリー: **3つの数字**（成果件数、利益（売上−費用）、顧客の作業時間）の Before → After と、**今日決めてほしいこと**
3. 前回の振り返り: 聞いた要望（目標・守る条件・判断軸）と、約束した宿題をすべて持ってきたこと
4. 現在地と伸ばし方: 実績の推移、媒体の4分類、競合状況、チャネルごとの役割
5. 計画: 短期（半年）と長期の2区切り。長期は件数とROASの関係を複数プランで
6. 進め方: 改善サイクル、判定ルール、うまくいかない場合
7. 体制と工数: 窓口の集約、顧客の作業が何時間から何時間に減るか、承認してほしい委任範囲
8. 費用と開始まで: 料金方式、承認方式、自社運用との利益比較、スケジュール、決めてほしいこと
9. Appendix: 月別の数字、業務ごとの工数表、季節の波、前提と確度の低いところ、数字の出し方、想定質問

## 2. 刺さる訴求
- **件数の増加と工数の削減の両立**。工数削減だけでなく、成果も伸びることを数字で示す。［事例001］
- 「手数料を払っても、自社運用より利益が多い」を同じ時点の数字で比較する。［事例001］
- 顧客の作業は業務ごとに「現在h → 移管後h」で見せ、**顧客に残る作業を正直に書く**（例: 営業にしか分からない成果の判定）。［事例001］

## 3. 料金の方式［事例001］
| 方式 | 中身 | 向いている顧客 |
|---|---|---|
| 料率型 | 媒体費（ASP・メディアへの支払い）に対して10%前後 | 媒体費が大きい顧客。成果と連動 |
| 工数型 | 作業時間 × 人月単価（作業と時間をすり合わせて決める） | 媒体費が小さい、または固定費を好む顧客 |

→ 自社の価格設計では「料率10%前後 ＋ 最低月額」を基本線として検討する（媒体費が小さい顧客は最低月額で、大きい顧客は料率で）。

## 4. 承認方式の選択肢［事例001］
- **現行型**: 承認した成果にだけ払う（承認・否認の作業が発生する）
- **全件承認型**: 全件に払う代わりに単価を下げる（不正時は不払い）。支払総額は同じに設計
- 全件承認型にすると、**承認・否認の作業そのものがなくなる**。自動化より先に「作業をなくす契約設計」を検討する。一部の媒体で試してから広げる

## 5. 委任範囲と上限（開始前に書面で決める）［事例001］
| 項目 | 代理店の判断でよい範囲 | 顧客への報告 |
|---|---|---|
| 単価の交渉 | 決めた範囲内 | 月1回まとめて |
| 新規提携 | 上限内 | 開始のつど |
| 表現のチェック | ルール内 | 迷ったものだけ相談 |
| データ連携 | 顧客のSFA/CRMから日次で自動連携 | — |
| 社内報告 | 報告資料は代理店が作る | — |

→ M1 の自律レベル（L0〜L3）は、この「項目ごとの範囲と上限」の形で顧客と合意する。

## 6. 契約条件
- 最低期間は6か月程度（改善1サイクルに4〜6か月かかり、それより短いと判定できない）［事例001］
- 開始前の準備（データ連携など）が遅れた分は延長
- 計画との差は毎月、計画全体は半年ごとに見直す

## 7. 想定質問と答え方［事例001］
| 質問 | 答えの骨子 |
|---|---|
| 具体的な施策と実現可能性は | 打ち手は3種類。どの媒体にどれを組むかは条件交渉に関わるので開始後の定例で順に。確かめられていることと、いないことを分けて言う |
| なぜその前提（件数○倍など）なのか | 根拠（媒体へのヒアリング等）と、自社案件での実績がまだないことを正直に。最初の数か月で検証する |
| 計画どおりに進まなかったら | 毎月差と理由を見せる。戻す → 前倒し → 引き直し の順で対応。上長向けの1枚を渡す |
| 契約の最低期間・見直し | 改善サイクルの長さから期間を説明 |
| 工数が減らなかったら | 3か月時点で業務ごとに実時間を確認し、原因（範囲・連携・報告形式）を特定して再提案 |
| 新規メディアはどう探すのか | 探し方の方法と候補数、小さく始めて判定件数で止める |
