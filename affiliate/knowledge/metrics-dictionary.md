# 指標辞書

広告主ごとに指標の名前と定義が違う。AIが混同しないよう、ここで名前・式・分母をそろえる。**顧客ごとの定義は導入時に必ず確認し、顧客の設定（Drive）に書く。**ここは一般形。［事例002〜011］

## ファネルの段階（成果地点の先）
人材系の例。顧客ごとに段階の数と名前が違うので、レポートは「段階を設定で変えられる」作りにする。

| 段階 | 意味 | 率の式（分母） |
|---|---|---|
| 発生（CV） | ASPで成果が発生 | CVR = 発生 ÷ クリック |
| 承認 | 広告主が承認した成果 | 承認率 = 承認 ÷ 発生 |
| 直接 | 広告主の計測で直接確認できた成果 | 直接率 = 直接 ÷ 発生 |
| 有効 | 重複・虚偽などを除いた有効な登録 | 有効率 = 有効 ÷ 発生 |
| 配布 | 担当者（コンサルタント等）に割り振られた登録 | 配布率 = 配布 ÷ 有効 |
| 面談・ヒアリング | 初回面談まで進んだ | 面談率 = 面談 ÷ 有効（または承認） |
| 推薦・求人提案・面接 | 次の工程 | 推薦率 = 推薦 ÷ 配布 |
| 成約・決定 | 入社などの最終成果 | 成約率 = 成約 ÷ 発生（または有効） |

- **CPAは段階ごとに出す**（承認CPA、有効CPA、面談CPA、成約CPA）。式は「費用 ÷ その段階の件数」。
- **成約は登録月に紐づけて追う（コホート）**。決定日ベースで数えると月の比較が狂う。

## 質の指標（顧客の「守る条件」）
| 指標 | 例 | 注意 |
|---|---|---|
| 属性の比率 | 正社員率、常勤率、有資格率、夜勤可能率、経験者率、対象エリア内率、転職時期（1か月以内・3か月以内）の比率、60歳以上率 | 分母（発生か有効か）を明記 |
| コア率 | 顧客が一番欲しい層（例: 常勤×短期で転職したい人）の比率 | 顧客ごとに定義が違う。導入時に式を決める |
| 低品質率（例: C率） | 顧客の評価で質が低いランクの比率 | 下げたい指標。下げると件数も減ることが多い |
| SF率・計測一致率 | ASPの成果のうち、顧客の SFA/CRM や計測ツールで確認できた比率 | 低いときは計測の故障か重複を疑う |

## 収益性
| 指標 | 式 | 注意 |
|---|---|---|
| ROAS | 成果の先の売上（粗利） ÷ 費用 | 手数料込みかどうかを明記 |
| 損益分岐CPA | 顧客の1件あたり粗利 × 許容する費用比率 | 雇用形態など層ごとに違う（正社員とパートで分岐点が違う） |
| EPC | 報酬 ÷ クリック（メディアから見た1クリックの価値） | メディアは EPC で掲載順位を決める。単価交渉の材料 |

## 掲載・競争
| 指標 | 意味 |
|---|---|
| 掲載順位、1位掲載率 | 比較・ランキング面で何位に載っているか、何%の面で1位か |
| 3位以内掲載率・5位以内掲載率・6位以下率・未掲載率 | 主要キーワードの検索結果に出る比較媒体のうち、何%でどの順位か（媒体調査） |
| マーケットシェア | その媒体が領域全体の成果の何%を持っているか |
| 競争水準（CPC） | 比較メディアのリスティング広告の入札の強さ |

## 管理
| 指標 | 意味 |
|---|---|
| 計上期間・締め日 | 顧客によって違う（月末締め、15日締め、19日締め、26日締めなど）。比較は同じ締めで |
| 着地見込み | 月末の予測（`report-playbook.md` の算式） |
| 保証率 | 競合が単価のうち何%を保証しているか（競合情報で使う） |
| 残クッキー | 掲載停止後も Cookie 有効期間内に発生する成果 |
