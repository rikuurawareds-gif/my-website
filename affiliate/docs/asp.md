# ASP 設計

## 登録候補（ジャンル決定後に確定）
| ASP | 特徴 | 優先度 |
|---|---|---|
| A8.net | 案件数が最大級。まずここ | 高 |
| もしもアフィリエイト | Amazon・楽天の物販に強い | 物販なら高 |
| バリューコマース | Yahoo!ショッピング系、大手案件 | 中 |
| afb | 美容・金融系、支払い条件が良い | ジャンル次第 |
| アクセストレード | 金融・通信・サブスク系 | ジャンル次第 |

## 案件の選び方（business-strategist が判断）
1. 報酬単価 × 想定CVR × 承認率で期待値を出す。
2. 承認率が低すぎる・否認条件が厳しい案件は避ける。
3. 規約（禁止キーワード、リスティング可否、表現ルール）を「ASP案件管理」に記録してから掲載。

## リンク管理
- 広告リンクはすべて `data-aff-id` を付け、`ASP案件管理` の「リンクID」と一致させる。
- 案件終了時は該当リンクを差し替え、ページを `99_アーカイブ` 扱いにする。

## 管理画面の数字の取り込み
国内ASPの多くはアフィリエイター向けの公開APIがないため、段階的に自動化する。
1. **最初**: 週1回、各ASPの成果レポートCSVを `ASP管理画面_日次取込` に貼る（オーナー作業、5分程度）。
2. **次**: Claude in Chrome（オーナーのログイン済みブラウザ）でCSVのダウンロードと貼り付けを代行する。
3. **APIがあるASP**: APIキーを環境の認証情報に登録し、週次タスクで自動取得する。
