# メディア向け: 案件変動の監視・通知（別商品）

## 何をするか
複数ASPの「報酬改定」「案件終了」「新規案件」「特単」のお知らせを1か所に集め、メディアが掲載している案件に関係するものだけを、すぐ分かる形で通知する。

## データの集め方
ASP管理画面へのログインやスクレイピングは規約違反のおそれがあるので、しない。代わりに:
1. 利用者ごとに専用の受信メールアドレスを発行する。
2. 利用者は、ASPからのお知らせメールをそのアドレスへ自動転送する設定をする（Gmail のフィルタなら1回で済む）。
3. 届いたメールを Claude で読み、「ASP・案件名・変更の種類・変更前→後・適用日」に整理する。
4. 利用者が「掲載中の案件リスト」を登録しておけば、関係するものを優先して通知する。

## 通知
LINE または メールで、要約を毎日1回と緊急分（案件終了など）はすぐに送る。

## 価格（仮）
月1,000〜3,000円。決済は Stripe などの定期課金。サポートの手間が売上に見合わないので、問い合わせは FAQ とチャットボットで受ける。

## 広告主向け事業との関係
利用者の許可を得たうえで、メディアの得意ジャンルや規模を把握できる。運用代行の顧客が新規メディアを探すときの候補になる。利用規約に明記し、本人の同意なしに連絡先を広告主へ渡さない。
