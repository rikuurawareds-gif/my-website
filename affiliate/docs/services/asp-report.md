# 商品2: 複数ASP統合レポート＋改善提案（広告主向け・月次）

## 何を納品するか
ASPごとにバラバラな成果データを1つにまとめ、Claude が分析コメントと翌月の打ち手を付けたレポート。

## データの受け取り
国内ASPの多くは広告主向けの公開APIが限られるので、**CSVを置いてもらう方式**から始める。
1. 顧客（またはこちらの運用担当）が、各ASPの管理画面から成果レポートCSVを `01_ASP成果CSV` に置く。
2. ファイル名や列の形から、どのASPのCSVかを自動で判定する。ASPごとの列の違いは変換表（`automation/asp-formats/`）で吸収する。
3. APIが使えるASPは、顧客の同意を得て順次 API 取得に切り替える。

顧客の管理画面のID・パスワードは預からない（漏洩時の責任が重すぎるため）。

## そろえる指標
ASP × メディア × 月 で、クリック・発生件数・発生報酬・承認件数・承認報酬・否認件数・承認率・CPA。

## レポートの構成
1. 今月の結論（3行）
2. 全体の数字と前月比・前年同月比
3. ASP別、メディア別の上位と下位
4. 変化が大きかったメディア（伸びた・落ちた・新しく発生した）
5. 承認率・否認理由の傾向
6. 翌月の打ち手（例: 特単を打つべきメディア、掲載を依頼すべき新規メディア、見直すべき成果条件）と期待される効果

保存先は `02_月次レポート`（Googleスプレッドシート＋要約のGoogleドキュメント）。要約は Chatwork でも送る。
