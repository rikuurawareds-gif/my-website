# デザインシステム（初期版）

ジャンル決定後に designer が色を調整する。トークン名は変えない。

| トークン | ライト | 用途 |
|---|---|---|
| `--c-bg` | #ffffff | 背景 |
| `--c-surface` | #f6f7f9 | カード・帯 |
| `--c-text` | #1d2129 | 本文 |
| `--c-muted` | #5b6270 | 補足 |
| `--c-primary` | #1f6feb | リンク・見出しアクセント |
| `--c-cta` | #e8590c | 申し込みボタン（1ページ1色に統一） |
| `--c-border` | #e3e6eb | 線 |

- 文字: 本文16px / 行間1.8 / 見出しは 28・22・18px
- 余白: 4の倍数（8, 16, 24, 32, 48）
- 角丸: 8px、ボタンは高さ52px以上（タップしやすく）
- CTAボタンはファーストビュー、比較表の直後、ページ末尾の3か所が基本
