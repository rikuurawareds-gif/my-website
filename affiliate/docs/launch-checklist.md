# リリースまでのタスク一覧

方針（2026-11-26 オーナー決定。決めたことは `decisions.md`）: **品質は低くてよいので最速でリリースし、後から上げる。** ただし次の3つは下げない: ①自社の宣伝表現（表記チェックを売る会社なので）②契約・規約（最初の有料契約の前に弁護士確認）③個人情報の扱い。

**リリースの定義**: 「見込み客が来て → 無料表記チェックを納品でき → 有料契約を結べ → 請求できる」状態。M1（Chatwork連携）などの自動化は、最初の顧客は人手＋AIで回すため、リリース条件に含めない。

記号: 🙋 オーナーの判断・本人の操作が必要 ／ 🤖 PM が進める ／ ✅ 完了
