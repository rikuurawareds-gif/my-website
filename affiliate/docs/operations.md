# 運用フロー

## A. オーナーからの依頼
オーナー → PM → 担当（並列）→ compliance-reviewer → PM → PR / 資料 → オーナー承認

## B. 新しい顧客の導入（目標: 顧客の作業30分以内）
1. 契約（業務委託契約・NDA・自律レベルの合意）— オーナー
2. PM: Drive に顧客フォルダを作って共有し、顧客管理シートに1行追加
3. 顧客: 提携メディア一覧と自社の表現ルールをフォルダに置く／Chatwork に運用担当アカウントを招待
4. 初回の表記チェックと現状レポートを1週間以内に納品

## C. 表記チェック（定期・自動）
スケジューラ → 記事の発見と取得 → ルール辞書 + Claude → レポート保存 → Chatworkで要約 →（運用代行プランなら）修正依頼の下書き → 承認キュー

## D. 月次レポート（毎月5営業日目までに）
顧客がCSVを置く（1〜3日）→ 自動で集計・分析コメント → PM が1件ずつ目を通す → 納品と翌月の打ち手の提案

## E. Chatwork 運用代行（常時）
メッセージ受信 → 分類（定型 / 依頼 / 条件・金額 / トラブル）→ 下書き → 自律レベルに応じて自動送信 or 承認キュー → 送信 → 記録

## F. 品質の振り返り（毎週）
- 承認キューで人が直した下書き、却下した下書きを見て、テンプレートとプロンプトを直す
- 表記チェックの誤検知・見落としを見て、ルール辞書を直す
