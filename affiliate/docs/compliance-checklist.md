# 公開前チェックリスト（自社のLP・資料用）

顧客向けの表記チェック商品のルールは `affiliate/checker/rules/` で別に管理する。

## 表示
- [ ] ファーストビューに「広告」または「PR」表記がある（ステマ規制）
- [ ] フッターに運営者情報、プライバシーポリシー、広告掲載ポリシーへのリンクがある
- [ ] GA4 を使っていることがプライバシーポリシーに書いてある

## 表現
- [ ] 「No.1」「最安」「業界初」に出典と調査時点がある。ないなら削除
- [ ] 「必ず」「絶対」「誰でも」など効果を保証する表現がない
- [ ] 価格・キャンペーン情報に確認日がある
- [ ] 体験談は実在のもので、効果を保証していない
- [ ] 健康・美容・医療: 薬機法の表現範囲内（「治る」「若返る」等なし）
- [ ] 金融: 元本保証・確実な利益をうたっていない

## ASP規約
- [ ] 案件ごとの禁止表現・禁止キーワードに抵触していない
- [ ] 商標の使い方が規約の範囲内

## 個人情報
- [ ] フォームで取る項目は必要最小限
- [ ] 取得目的と第三者提供の有無を明記
- [ ] 回答データの保存先がGitHub・公開場所ではない
