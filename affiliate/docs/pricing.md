料金をどこかに書くときは、このファイルを元にする（LP・決裁シート・llms.txt・営業文・申込書）。変えるときは PM が `decisions.md` に記録してからここを直す。

## 考え方
- 主力は **窓口代行**（ASP・メディアとの日々のやり取りを、アフィまかせの担当者が代わりに受けて返す）。ほかの作業はオプションで足して、順に手離れさせる
- 窓口代行の形: ASP・メディアには「アフィまかせの担当者」として名乗る（代行していることは隠さない）。やり取りは主に Chatwork で、同じルームにアフィまかせの担当者とお客さまの担当者が一緒に入る。任された範囲はアフィまかせ側がその場で返し、判断が要るものだけお客さまの担当者に回す
- 価格の根拠は「担当者の時間 × 時給5,000円」。上長が費用対効果で判断できるようにする

## 料金（税別・月額）
| 区分 | 中身 | 料金 |
|---|---|---|
| **基本：窓口代行** | ASP・メディアとの日々のやり取りの代行（Chatwork に同席し、任された範囲は即答）。週1回のまとめ報告 | **30,000円**（ASP 3社まで）。4社目から1社につき +10,000円 |
| オプション：成果承認 | 承認・否認の判定と、ASP 管理画面への反映。**自動判定に使える CSV データ（注文・申込データなど）をいただけることが前提** | ASP 1社につき **3,000円**。5社目からは1社につき **2,000円** |
| オプション：表記チェック | 提携サイトの表記の一次チェック（新規・既存を問わない）と、修正依頼の文面 | **月20サイトまで 10,000円〜**（仮。内容と上限は後で詰める） |
| オプション：月次レポート | 複数 ASP の成果の集計と、社内報告用の資料 | **10,000円** |
| オプション：新規メディアの調査・開拓 | まだ載っていない面の調査と、掲載の依頼 | **40,000円** |
| **まるごとパック** | 窓口代行（ASP 3社まで）＋オプションすべて | **90,000円**（別々に頼むと 99,000円）。4社目からの追加は窓口代行と成果承認の加算に同じ |
| 表記チェックのみ（窓口代行なし） | 月20サイトまでの一次チェック、修正依頼の文面、表記のルール（レギュレーション）の作成 | **20,000円** |

- 共通: 初期費用 0円、最低契約期間 3か月（以後1か月ごとの自動更新）
- アフィリエイト代理店: 1アカウント（担当する広告主1社）ごとに、上と同じ料金表
- ASP・メディアへのお支払い（媒体費）が月100万円を超える規模: 別途お見積もり
- 表記チェックは一次チェックで、法的な最終判断ではない（すべての表示に添える）

## 工数診断・決裁シートの前提（`site/assets/diagnosis.js` の ASSUMPTIONS）
- 時給の既定値: 5,000円（診断で選べる）
- プランごとの委託費と、委託後にお客さまに残る工数（月）:
  - 窓口代行だけ: 委託費 30,000円＋（ASP 4社目からの加算）。残る工数 = いまの工数 −「ASP担当とのやり取り」「メディア対応・掲載確認」の時間 ＋ 確認の時間 月2時間
  - まるごとパック: 委託費 90,000円＋（ASP 4社目からの加算: 1社につき窓口 10,000円＋承認 2,000〜3,000円）。残る工数 = 月4時間（週1回の確認×約1時間）
- どのプランでも「試算です。実際の工数と効果は運用の状況で変わります」と前提を並べて出す。差額がマイナスのときもそのまま出す
