# サイト全体のデザイン設計（2026-11-28 サイトデザイン担当）

## 目的と、なぜ
- アフィまかせのサイト（LP・コラムの記事と一覧・プライバシーポリシー）を、会社サイト ixs-llc.com と同じトーンでそろえる。会社とサービスで信用をつなげるため（decisions.md 2026-11-28）
- **読み手の主役は上長（導入を決める人）。** 実際には「担当者が上長にページを見せる → 上長がさらに決裁者に見せる」流れが多い（オーナー回答 2026-11-28）。そのため、**診断結果を、そのまま決裁に回せる1枚（決裁シート）にする**のがこのデザインの主役
- アフィリエイト担当者の悩みと、それが任せたあとにどう消えるかを、自作の SVG イラストと図解で見せる（オーナーの希望）

## ゴール
1. 工数診断の結果が「決裁シート」になる。紙1枚の体裁で、いまの工数・委託後の工数・削減時間・人件費換算・費用対効果（月・年）・作業ごとの内訳・残る作業・前提条件・よくある懸念への答え（チェックの質／メディアが増えるか）が載る
2. 決裁シートは **印刷・PDF 保存** と **リンクの共有**（回答を URL の # に入れる。個人情報は入れない）ができ、上長がリンクを開くと同じ結果が出る。宛名（会社名）は任意入力で、画面と印刷にだけ使い、どこにも送らない
3. 共通のイラスト体系（下の「モチーフ」）を作り、LP・コラム・一覧で使う
4. コラムの記事ページと一覧を、同じ部品で整える（記事の見出し図、カテゴリの絵、読みやすい本文）
5. プライバシーポリシーを、同じ見た目で読みやすくする

## しないこと
- **LP の文言・料金表は確定させない。** 売り方の変更（主力 = 連絡窓口の代行、ほかはオプション）を PM がオーナーと詰めている。PM から文言と料金が来るまでは、いまの文言のまま見た目と図だけを差し替える。新しい構成（主力＋オプション）の部品は作っておき、文言が来たら差し込む
- 他社の名前は出さない。顧客の実績に見える書き方はしない（まだ実績はない）
- 外部の素材・有料ツールは使わない。イラストはすべて手書きの SVG
- `site/content/*.md`、`config.js`・`track.js`、build.py の仕組み（Markdown 変換・sitemap・llms.txt・構造化データ）には触らない

## 失敗とみなすこと
- 決裁シートの数字が、根拠を示さずに「得をする」と言い切っている（前提条件と「目安の試算」を必ず同じ紙に載せる）
- イラストが飾りに終わり、何の悩みのどの変化かが読めない
- スマホ（375px）で横にはみ出す、キーボードで操作できない、動きを減らす設定を無視する

## 制約
- トーン: 濃紺（#070b18 系）・青→水色のグラデーション・Noto Sans JP の太字。変数は `site/assets/site.css` の先頭（既存のトークン名は変えない）
- push するとそのまま公開される。公開前に `checker/check.py`、宣伝文を変えたら `compliance-reviewer`
- 決裁シートの計算に入る「委託後に残る工数」と「委託費」は主張に関わる数字なので、PM が決める。コードでは1か所の定数にまとめ、PM の確認が取れるまでは現行の LP と同じ前提（月5万円・残る作業は週1回の確認）を仮に置く

## 進め方の候補と選んだもの
| 案 | 中身 | 長所 | 短所 |
|---|---|---|---|
| A. 部品から順に差し替える（選択） | 共通 CSS とイラストを先に作り、LP はいまの文言のまま見た目と図を入れ替える。決裁シートを作る。記事・一覧・プライバシーも同じ部品に。新構成の LP は文言が来てから | 文言が未定でも公開を止めずに進められる。PM の決定を待たない部分が大きい | LP の全体構成の見直しは2段階になる |
| B. 新しい LP を下書きで丸ごと作る | 新構成の LP を別ファイルで作り、文言が来たら差し替え | 一度で完成形が見える | push すると下書きも公開されてしまう。文言なしで作ると作り直しが多い |
| C. 決裁シートだけ先に作る | 主役だけ先行 | 早い | イラストの体系がないまま作ると、あとで見た目がずれる |

オーナーから「もろもろ進めて OK」（2026-11-28）。進め方はデザイン担当の判断で A。

## デザインの方針
### 色（既存トークンを使い、足すのは2つ）
| 名前 | 値 | 役割 |
|---|---|---|
| `--navy` | #070b18 | 地（ヘッダー・ヒーロー・フッター） |
| `--blue` → `--cyan` | #3366ff → #22d3ee | 「1本にまとまった連絡」の線、主要ボタン、強調の数字 |
| `--paper` | #fbfcff | 決裁シートの紙 |
| `--ink` | #0f1424（= `--text`） | イラストの線、本文 |
| `--knot` | #9aa4bf | 絡まった連絡の線（悩みの側） |
| `--bg-sub` | #f4f6fb | 帯の地 |

### 文字
- Noto Sans JP の1書体（ixs-llc.com に合わせる）。見出し 900、本文 400、数字は `font-variant-numeric: tabular-nums`
- 本文は記事で 17px・行間 1.9、1行は全角 40字前後（最大幅 42em）
- **英字の大文字の見出し飾り（PROBLEM / SERVICE などの .en）と、英単語が流れる帯は外す。** どのサイトにもある飾りで、内容を伝えていないため。代わりに日本語の見出しだけで立たせる
- 見出しの一語だけ色を変える処理（.grad-text）はヒーローの1か所にも使わない

### モチーフ: 「絡まった連絡の線が、1本にまとまる」
主力が「連絡窓口の代行」になるので、悩み → 解消 を **線** で描く。
- 悩みの側: 担当者から ASP・メディア・社内へ、灰色の線が何本も伸びて絡まっている
- 任せたあと: 線はアフィまかせの窓口でいったん束ねられ、担当者には **青→水色の線が1本だけ** 届く（週1回のまとめ）
- イラストは線画（線の太さ 2px、角は丸）。人物は丸い頭と胴の簡単な形で、顔は描かない。塗りは最小限で、青→水色のグラデーションは「まとまった線」にだけ使う
- 動き: ヒーローで1回だけ、絡まった線がほどけて1本になる（約1.6秒）。`prefers-reduced-motion` のときは完成した状態で止める。ほかの場所では自動の動きを入れない

### 決裁シート（主役）
```
┌ 画面（濃紺の机の上に、白い紙が1枚） ─────────────────┐
│  [宛名: ____ 御中（任意）]   [印刷・PDF保存] [リンクをコピー] │
│ ┌ 紙 ───────────────────────────────┐ │
│ │ アフィリエイト運用 委託の試算         作成日 2026.11.28 │ │
│ │ ──────────────────────────────── │ │
│ │  いま 月48時間  ──▶  委託後 月4時間                 │ │
│ │  削減 月44時間 ＝ 人件費 月17.6万円（時給4,000円）     │ │
│ │  委託費 月5万円 → 差し引き 月12.6万円／年151万円     │ │
│ │ ──────────────────────────────── │ │
│ │  作業ごとの内訳（いま ■■■■■ / 委託後 ■）              │ │
│ │  御社に残る作業 ・週1回のまとめ ・範囲外の判断        │ │
│ │  よくある懸念  チェックの質 → 無料の表記チェック       │ │
│ │               メディアが増えるか → 無料の伸びしろ診断 │ │
│ │  前提条件（小さく、必ず同じ紙に）                     │ │
│ │  アフィまかせ／合同会社IXS                            │ │
│ └───────────────────────────────┘ │
│  [この試算をもとに相談する]                              │
└──────────────────────────────────────┘
```
- 紙の比率は A4 縦。印刷用 CSS で紙だけを印刷し、1枚に収める
- 数字の大きさの順: 差し引きの額（年）が最大、次に削減時間。「いくら得か」が先に目に入るように
- 差し引きがマイナス・小さい場合は、そのまま正直に出し、「工数が小さいうちは、表記チェックなど一部だけ任せる方法もあります」と書く（PM が文言を確認）

### レイアウト
- 左揃えが基本。中央揃えは決裁シートの周りと、最後の相談の帯だけ
- LP の悩みの節: 2列（イラスト＋短い文）を3段。カードの箱は使わず、イラストと文字で区切る
- コラム記事: 見出しの帯にカテゴリの絵、本文は 42em 幅。本文中の CTA は「あなたの運用で決裁シートを作る」に統一
- コラム一覧: SEO・AIO が作った構成（まずはここから・絞り込み・2列カード）はそのまま。カードにカテゴリの絵を足し、見た目をそろえるだけ

## 決まっていないこと（PM に回す）
1. 新しい売り方の文言と料金表（来たら LP の構成を差し替える）
2. 決裁シートの「委託後に残る工数」と「委託費」の前提と、差し引きの出し方・注記の文言
3. 決裁シートの宣伝文の compliance-reviewer の確認

## 作る人に任せること
- イラストの細部（線の本数・配置）、余白の数値、ブレークポイント
- 共有リンクの # の書式（回答の値だけを短く入れる）
