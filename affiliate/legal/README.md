# 契約・規約のたたき台

**すべて弁護士確認前のたたき台。** 最初の有料契約の前に、オーナーが弁護士に確認を依頼する（`../docs/launch-checklist.md` D7）。無料の表記チェックや商談には、この版で進めてよい。

| ファイル | 使う場面 |
|---|---|
| `terms.md` | 利用規約。申込書とセットで契約の共通ルールになる |
| `application-form.md` | 申込書（個別契約）。顧客ごとの料金・期間・範囲 |
| `nda.md` | 秘密保持契約。商談で成果データを見る前に結ぶ |
| `data-processing.md` | 個人情報の取扱いに関する覚書。顧客の会員データを預かる場合 |
| `delegation.md` | 委任範囲の合意書。「範囲内はこちらの判断」を決める |

【】は、オーナーが決める値（運営者名、所在地、連絡先、料金など）。

## 弁護士に特に見てもらう点
1. 損害賠償の上限と免責（第13条・第14条）
2. 表記チェックの位置づけ（第6条）が弁護士法72条との関係で十分か
3. AI・外国のクラウドサービスの利用（第8条、覚書第5条）と個人情報保護法の越境移転
4. ASP・メディアとのやり取りを顧客の代わりに行う権限（委任範囲の合意書）

## 弁護士の確認をどう頼むか（顧問弁護士がいない場合）
単発で頼める窓口がある。料金は記事の目安で、弁護士ごとに違う。
| 窓口 | 内容 | 目安 |
|---|---|---|
| [ココナラ法律相談](https://legal.coconala.com/) | 弁護士を探して、相談・契約書の確認を依頼できる。分野・地域で検索 | ネット相談の詳細 3,000〜10,000円程度、電話・面談 5,000〜30,000円程度 |
| [弁護士ドットコム](https://www.bengo4.com/) | 企業法務・IT分野の弁護士を探して依頼 | 弁護士ごと |
| 契約書の確認の相場 | 定型的なもの3〜5万円、業務委託など複雑なもの10〜15万円程度 | 1通あたり |
| AI のレビューサービス | 一般的なリスクの指摘まで。事業固有の判断は弁護士が必要 | 年6万円程度〜 |

**おすすめの頼み方（費用を抑える）**: 利用規約・申込書・個人情報の覚書・委任範囲の合意書・プライバシーポリシーを **まとめて1回** で依頼し、「アフィリエイト運用代行（広告主向け、表記の一次チェックを含む）」と伝える。NDA は一般的なひな形に近いので後回しでよい。依頼文は `lawyer-request.md`。
