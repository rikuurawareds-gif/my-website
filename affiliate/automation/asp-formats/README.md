# ASPの成果CSVの形式

`report-builder` が、ASPごとのCSVを共通の形（ASP × メディア × 月 × 指標）にそろえるための変換表を置く。

## 集め方
**広告主側の管理画面のCSV** が必要（メディア側のアカウントでは、広告主側の形式は分からない）。
1. オーナーが、ASPごとに **見出し行と、数字を書き換えたダミーの行2〜3行** を用意する（実データ・顧客名は入れない）
2. Drive の `05_計測・KPI` に「ASP名_レポート種類.csv」で置く
3. PM が読み取り、ここに `<ASP名>.md`（列の意味、文字コード、日付の形式、承認状態の値）を作る

## 共通の形
| 列 | 意味 |
|---|---|
| asp | ASP名 |
| month | 対象月（発生月または確定月。どちらかを明記） |
| media_id / media_name | メディア（サイト）ID・名前 |
| program_id | 広告主のプログラムID |
| clicks | クリック数 |
| occurred | 発生件数 |
| occurred_reward | 発生報酬（税抜） |
| approved | 承認件数 |
| approved_reward | 承認報酬（税抜） |
| rejected | 否認件数 |
| fee | ASP手数料（分かる場合） |
