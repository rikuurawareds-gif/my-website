# 作業文書（sagyo-bunsyo）

オーナーの作業を「貼るだけ」にする指示文を作る。オーナーに残すのは、本人でなければできない数秒〜数分の操作だけにする。

## 1. 作業を把握する
- 引数が「残り全部」や空なら、`affiliate/docs/roadmap.md` の未完了と `affiliate/ops/owner-tasks/README.md` の一覧から、オーナーが関わる作業を洗い出す。
- 必要な値（Drive の ID、URL、前の作業の結果）は `affiliate/docs/drive.md` と、Drive の「作業結果の受け渡し」（`1h3CYlzcAakR8DB2nmBx2qvGakh9Z7z5Zahi3_SNWSzM`）を読んで集める。
- **PM（Claude Code）が自分でできることは指示文にしない。** リポジトリの変更、Drive のファイル作成・読み書き、Gmail の下書き、調査や文章作成は PM がやる。指示文にするのは、オーナーのブラウザやパソコンでしかできない作業だけ。

## 2. 誰にやらせるか決める
| 実行者 | 向いている作業 |
|---|---|
| **Claude in Chrome** | オーナーがログインしている Web サービスの画面操作（設定画面、管理画面、フォーム入力、アカウント作成） |
| **コワーク（Cowork）** | パソコン上のファイルやアプリを使う作業、複数のサイトをまたぐ調査をシートにまとめる作業、長めの文書づくり |
| **PM が自分で** | 上のどちらでもないもの |

## 3. オーナーにしか残せないもの（指示文では「止まってオーナーに頼む」にする）
- パスワード入力、二段階認証、SMS・メールの認証コード、CAPTCHA
- 外部サービスに自分のアカウントへのアクセスを許可する画面（OAuth の「許可」、Google の「安全ではないページに移動」など）
- 支払い、カード情報、本人確認書類
- OS のファイル選択ダイアログ（ファイルのアップロード）
- 公開してよいかの最終判断（指示文を貼った時点で承認済みとみなせる範囲は、指示文に明記する）

それ以外はすべてエージェントにやらせる。オーナーに残る操作は、指示文の冒頭に「あなたがやること（目安の時間）」として一覧にする。

## 4. 指示文の型（必ずこの順で書く）
```
あなたは【役割】です。オーナーのブラウザ（ログイン済み）で作業します。
作業番号: 【NN】　作業名: 【作業名】

# 目的
【何のために、何を完成させるか。1〜3行】

# 前提
- 【ログインしているサービス、使う URL、前の作業の結果】

# 守ること
- 指示にない設定・購入・削除・公開はしない。迷ったら止まって確認する。
- パスワード、認証コード、CAPTCHA、アクセス許可の画面、支払い、ファイル選択は、止まってオーナーに頼む。オーナーが終えたら続きから再開する。
- パスワード・APIキー・認証コードを、どこにも書き写さない。
- 【この作業に固有の禁止事項】

# 手順
1. 【具体的な画面と操作。入力する値はそのまま書く】
2. ...

# 終わったら
1. 次の Google ドキュメントを開き、一番下に結果を追記する:
   https://docs.google.com/document/d/1h3CYlzcAakR8DB2nmBx2qvGakh9Z7z5Zahi3_SNWSzM/edit
   形式:
   ## 【NN】【作業名】（YYYY-MM-DD HH:MM）
   - 状態: 完了 / 途中で停止（理由）
   - 結果: 【PM に渡す値の一覧】
   - オーナーの対応が必要なこと: 【なければ「なし」】
2. オーナーに、終わったことと、残っている対応があればそれを短く伝える。
```

## 5. 書くときの注意
- 入力する値（名前、説明文、設定値、URL）は指示文の中に **そのまま** 書く。エージェントに考えさせない。
- 画面の名前やボタン名は変わることがあるので、「見つからない場合は似た名前のメニューを探し、それでもなければ止まって報告」と添える。
- コードを貼る作業は、公開リポジトリの raw URL から取得させる（`https://raw.githubusercontent.com/rikuurawareds-gif/my-website/<ブランチ>/<パス>`）。
- 前の作業の結果が必要なら「受け渡しドキュメントの【NN】の結果を読む」と書き、依存関係を明記する。
- このリポジトリは公開なので、オーナーのメールアドレス・電話番号・パスワード・顧客名を指示文に書かない。必要なら「オーナーに聞く」とする。

## 6. 保存と返答
- 指示文は `affiliate/ops/owner-tasks/<NN>-<短い英語名>.md` に保存し、`affiliate/ops/owner-tasks/README.md` の一覧（順番、実行者、所要、依存、状態）を更新する。
- オーナーへの返答には次を入れる:
  1. 貼る場所（Chrome か コワーク）と、貼る順番
  2. 指示文そのもの（コードブロックで、すぐコピーできる形）
  3. オーナーに残る操作と目安の時間
  4. 「終わったら『終わった』とだけ伝えてください」。PM は受け渡しドキュメントを読んで次へ進む
- オーナーから「終わった」と言われたら、受け渡しドキュメントを読み、結果をリポジトリや設定に反映し、一覧の状態を更新する。
